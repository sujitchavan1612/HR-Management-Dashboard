# HR Management Dashboard

## Project Overview
Developed an interactive HR Management Dashboard using Power BI, MySQL, SQL, and Python to analyze employee data and monitor workforce performance.

## Project Objectives
- Analyze total and active employees.
- Monitor employee hiring and attrition.
- Evaluate department-wise employee distribution.
- Analyze gender and job-level distribution.
- Identify workforce trends and HR insights.

## Tools & Technologies
- MySQL Workbench
- SQL
- Microsoft Power BI
- DAX
- Python
- Jupyter Notebook

## Project Structure
- `data/` – HR dataset files
- `powerbi/` – Power BI dashboard
- `python/` – HR data analysis notebook
- `screenshots/` – Dashboard screenshots
- `sql/` – SQL queries and data-cleaning scripts

## Dataset
The project uses an HR dataset containing 10,000 employee records.

## Data Cleaning
- Checked missing values.
- Validated unique Employee IDs.
- Checked duplicate records.
- Validated age and salary values.
- Checked employment status and date consistency.

## Dashboard Features
- Total Employees
- New Hires
- Exited Employees
- Attrition Rate
- Average Tenure
- Department-wise Analysis
- Gender Distribution
- Hiring and Attrition Trends
