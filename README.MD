# HR Management Dashboard | Power BI, MySQL & Python

## Project Overview

The HR Management Dashboard is a data analytics project developed to analyze employee information and monitor workforce performance.

This project uses SQL for data cleaning and validation, Python for data analysis, and Power BI for interactive dashboard development.

## Dashboard Preview

![HR Management Dashboard](<Screenshot 2026-11-02 164441.png>)

## Project Objectives

- Analyze overall employee workforce.
- Monitor new hires and employee exits.
- Evaluate employee attrition.
- Analyze department-wise workforce distribution.
- Understand gender and job-level distribution.
- Track hiring and attrition trends.
- Support data-driven HR decisions.

## Dataset Information

- Total employee records: 10,000
- Unique Employee IDs: 10,000
- Departments: 8
- Employment categories: Active and Exited

## Data Cleaning & Validation

Performed SQL-based data quality checks:

- Checked missing values.
- Validated unique Employee IDs.
- Checked duplicate employee records.
- Validated employee age.
- Checked salary values.
- Reviewed department and job-role distribution.
- Validated employment status.
- Checked HireDate and ExitDate consistency.

## Dashboard Features

### Key Performance Indicators (KPIs)

- Total Employees
- New Hires
- Exited Employees
- Attrition Rate
- Average Tenure

### Visualizations

- Department-wise Employee Distribution
- Gender Distribution
- Job Level Distribution
- Hiring vs Attrition Trends
- Attrition Rate by Department
- Employee Distribution by Location
